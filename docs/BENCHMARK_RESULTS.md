# MUMU 비교 측정 결과
## 1. 비교 조건
### 원본 무무의 `llama-4-maveric`은 watsonx.ai 계정 만료로 인해 개선버전과 동일한 모델로 대체.

`maverick`과 동일한 성능을 가진 다른 모델들을 사용하려 여러 서비스를 탐색해 보았지만, 이미 너무 예전 모델이라서 서비스 되지 않고있었습니다. <br>
따라서 개발당시 시점의 무무의 llm성능을 완전히 복원하지 못하였고, `gemini-3.5-flash-lite`로 llm은 동일한 성능으로 진행하였습니다.


| 항목 | 조건 |
|---|---|
| 원본 무무 | [문서참조](../legacy/README.md) |
| 개선 무무 | [문서참조](../README.md) |
| 생성 설정 | temperature·seed는 미지정 |
| 대화 시험 | 4개 시나리오 × 3턴 × 2버전, 성공 응답 24건 수집. 각 버전은 자신의 직전 답변을 다음 턴에 전달 |
| 순서 | 턴마다 두 버전의 호출 순서를 교대로 바꾸어 실행 |
| 음성 시험 | `eval_clean` 음성 24개를 난수 시드 `20261120`으로 선정. 의문문·평서문 각 12개, 짧은 음성 16개와 긴 음성 8개 사용. |
| 장비 | 동일한 Windows PC에서 CPU 스레드 4개로 실행, GPU 미사용 |

각 버전의 실제 대화·STT 핵심 함수를 호출한 시험으로 진행하였습니다. 

원본 무무 함수는 소스에서 추출하여 사용하였으며, 마이크만 동일 음성 파일 재생으로 대체하였습니다.

<br><br>

## 2. 답변 길이와 토큰

| 지표 · 응답당 평균 | 원본 무무 | 개선 무무 | 관찰 결과 |
|---|---:|---:|---|
| 답변 글자 수 · 공백 포함 | 159.25자 | 43.08자 | 72.9% 감소 |
| 출력 토큰 | 95.58 | 25.92 | 72.9% 감소 |
| 입력 토큰 | 607.50 | 1660.08 | 173.3% 증가 |
| 전체 토큰 · 입력+출력 | 703.08 | 1686.00 | 139.8% 증가 |

토큰은 API가 반환한 `usage_metadata`로 집계하였습니다.

답변의 길이는 더욱 짧아졌지만, 더 긴 시스템 프롬프트와 실시간 동기화를 위한 현재 시각 등 입력토큰의 증가로 인해 **전체 토큰은 오히려 증가**하였습니다.

이는 무무의 성능 향상과 여러 편의성 등에 의한 토큰 증가임을 감안하고 비교하였습니다.

## 3. 응답 시간

| 서버 측 지표 · 버전당 12건 | 원본 무무 | 개선 무무 |
|---|---:|---:|
| 전체 답변 완료 · 평균 | 2.137초 | 1.969초 |
| 전체 답변 완료 · 중앙값 | 1.466초 | 1.238초 |
| 전체 답변 완료 · 최댓값 | 9.474초 | 8.795초 |
| 첫 표시 가능 텍스트 · 평균 | 2.137초 | 1.933초 |
| 첫 표시 가능 텍스트 · 중앙값 | 1.466초 | 1.236초 |

원본 무무는 답변이 완성되어 반환된 시점을, 개선 무무는 `on_chunk`에 첫 번째 비어 있지 않은 텍스트가 도착한 시점을 첫 표시 가능 시점으로 측정하였습니다.

개선 무무에서는 첫 텍스트와 전체 완료의 평균 차이가 약 36ms로 작게 나타났습니다.

## 4. 전체 음성 인식 결과

모델은 먼저 로드하고 한 번 예열한 뒤 전사 함수의 실행 시간을 측정하였습니다.
**이는 24개 표본 결과로, 전체 한국어 음성의 오류율이 아님**
| 지표 | 원본 무무 Whisper base | 개선 무무 Whisper small |
|---|---:|---:|
| CER | 23.29% · 119/511 | 10.18% · 52/511 |
| 정답과 완전히 일치한 문장 | 1/24 | 8/24 |
| 물음표 누락 · 의문문 12개 | 4/12 | 5/12 |
| CPU 전사 시간 · 평균 | 1.069초 | 4.729초 |
| CPU 전사 시간 · 중앙값 | 0.764초 | 4.435초 |

이번 표본의 CER은 **13.11%p, 상대적으로 56.3% 감소**하였습니다. 반면 평균 CPU 전사 시간은 약 4.42배로 증가하였습니다.

CER은 Unicode NFC 정규화 후 공백·문장부호를 제외한 글자 기준으로 `(치환+삭제+삽입)/정답 글자 수`를 계산하였습니다. 

<br><br>

## 5. 개선 정리

- 동일 모델을 연결한 대화 시험에서 평균 답변 길이 약 159자에서 43자, 출력 토큰 약 73% 감소를 확인하였습니다.
- 한국어 평가 음성 24개 기준 CER을 23.29%에서 10.18%로 감소하였습니다.
- 고정 길이 5초 녹음 대신 발화 구간을 전사하여 긴 입력의 잘림이나 짧은 입력의 대기시간이 감소하였습니다.
